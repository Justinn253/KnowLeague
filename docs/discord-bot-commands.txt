KnowLeague Discord slash-command inventory
==========================================

Administrative means the command is restricted at execution time. “Configured
staff role” is set in Discord Configuration; “Discord Administrator” requires
the Discord Administrator permission. All other commands are member-facing.
`hidden=true` means the command response is private to the sending member and
can be used in any channel where that member may use application commands.
